## หลักการนำเข้า
1. ไฟล์แผนใช้เป็นแหล่งหลักของโครงการและวงเงินอนุมัติ
2. แท็บรายโครงการในทะเบียนใช้เป็นแหล่งรายการเคลื่อนไหว ไม่ใช่แหล่งสร้างโครงการซ้ำ
3. แท็บยอดคงเหลือและแท็บสรุปใช้สำหรับ **ตรวจสอบยอด** ไม่ใช่นำเข้าเป็นรายการเบิกจ่ายซ้ำ
4. เก็บเลขโครงการ 1–39 และแหล่งที่มา (ชื่อไฟล์/ชื่อแท็บ/เลขแถว) ในแต่ละระเบียน
5. อย่าใช้ชื่อแท็บที่ถูกตัดสั้นเป็นชื่อโครงการทางการ ให้ตรวจชื่อจากข้อมูลภายในชีต
6. ตรวจรูปแบบวันที่ พ.ศ., สูตร Excel, รายการคืนเงิน/โอนย้าย และยอดติดลบก่อนนำเข้ารายการ
7. ก่อนอนุญาตเขียน Firestore ต้องกำหนดบทบาทผู้ใช้และ Security Rules ที่ตรวจสิทธิ์ฝั่งเซิร์ฟเวอร์

## Firestore collections (เป้าหมาย)
- `fiscalYears/{year}`
- `departments/{id}`
- `fundingSources/{id}`
- `projects/{year_projectNo}`
- `projects/{year_projectNo}/activities/{activityId}`
- `allocations/{id}`
- `transactions/{id}`
- `users/{uid}`
- `auditLogs/{id}`

สถานะ: โครงสร้างแท็บตรวจแล้ว; การแมปคอลัมน์และข้อมูลธุรกรรมระดับแถวยังต้องตรวจต่อก่อน import.
