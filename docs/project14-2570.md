# โครงการ 14 ปี 2570: จ้างครูผู้สอนแบบรวมโครงการ

หน้าโครงการ เอกสาร และรายงานใช้ยอดรวมตามประเภทเงิน ไม่มีการเลือกกลุ่มสาระเป็นกิจกรรมย่อย ส่วนข้อมูลทะเบียนดั้งเดิม แถวรายการ และปลายทางการยืมยังเก็บเดิมเพื่อให้ตรวจสอบและแก้ไขประวัติได้

ข้อกำหนดนี้ใช้เฉพาะโครงการ 14 ปี 2570 เท่านั้น ประเภทเงินต่างกันยังตรวจวงเงินแยกกัน ยอดรายทะเบียนเก่าอาจติดลบภายในเมื่อใช้วงเงินรวม แต่การอ่านผ่าน API จะรวมทะเบียนประเภทเงินเดียวกันเสมอ การบันทึกและกู้คืนตรวจยอดรวมบน server ภายใน transaction เดิม ไม่ใช้ยอดที่ browser ส่งมาเป็นฐานอนุมัติ

## เผยแพร่

1. ลงชื่อเข้า Firebase CLI ด้วยบัญชีที่มีสิทธิ์ในโครงการ `school-budget-3e69d`
2. จาก root ของ repository ติดตั้ง dependency ด้วย `npm install --prefix functions`
3. Deploy เฉพาะ API: `npx firebase-tools deploy --only functions:school-budget:budgetApi --project school-budget-3e69d`
4. เผยแพร่ frontend ผ่าน GitHub Pages โดย merge PR นี้ หลัง API พร้อมใช้งาน
5. ตรวจหน้า `budget-entry.html?year=2570&project=14`: ไม่แสดงชื่อกลุ่มสาระในตัวเลือก ยอดรวมต้องเท่ากับผลรวมทะเบียนเดิม รายการเก่าต้องแสดงครบ และเอกสาร งบ 1 / งบ 2 ไม่ต้องเลือกกิจกรรม

ไม่ต้องย้ายหรือลบเอกสาร Firestore และไม่ต้อง deploy security rules
