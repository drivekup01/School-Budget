# การเพิ่มกิจกรรมจากงบเดิม

ผู้ดูแลระบบและฝ่ายงบประมาณเปิด **โครงการและกิจกรรม → เพิ่มกิจกรรม** แล้วเลือกฝ่าย โครงการ ชื่อ และผู้รับผิดชอบ

- **แบ่งจากงบเดิม** (ค่าเริ่มต้น): เลือกประเภทเงินและแหล่งงบต้นทาง กรอกยอดแบ่งให้กิจกรรมใหม่ ระบบหักจากยอดจัดสรรต้นทางและเพิ่มให้กิจกรรมใหม่ในธุรกรรมเดียว ยอดจัดสรร รายรับ และยอดคงเหลือรวมของโครงการ/ฝ่ายงานเท่าเดิม
- **เพิ่มงบใหม่**: ใช้เมื่อได้รับเงินเพิ่ม ยอดที่กรอกจะเพิ่มยอดรวมโครงการและฝ่ายงาน กรอก 0 ได้หากต้องการสร้างกิจกรรมไว้ก่อน

แหล่งงบเดิมเลือกได้ทั้งงบโครงการที่ยังไม่แยกกิจกรรม และกิจกรรมเดิมในประเภทเงินเดียวกัน แบ่งได้ไม่เกินยอดจัดสรรตั้งต้นที่ยังไม่ได้แบ่ง โดยไม่ใช้ยอดคงเหลือหลังใช้จ่ายเป็นเพดาน ระบบอ่านทะเบียนล่าสุดและตรวจ revision อีกครั้งก่อนบันทึก หากข้อมูลเปลี่ยนให้เปิดหน้าต่างเพิ่มกิจกรรมใหม่

ระหว่างรอย้ายรายการใช้จ่าย ยอดคงเหลือต้นทางอาจติดลบและแสดงเป็นรายการค้างให้แก้ไข ส่วนยอดคงเหลือรวมโครงการเท่าเดิม

แผงตรวจสอบการแบ่งงบ / งบ 1 แสดงฉบับร่าง ข้อมูลที่ขาด กิจกรรมที่ยังไม่เลือก รายการที่ไม่พบการหักเงิน การหักเงินผิดกิจกรรม/ประเภท/จำนวน ตลอดจนรายจ่ายที่ยังอยู่ต้นทาง ปุ่มเปิดแก้ไข งบ 1 ใช้การบันทึกเอกสารเดิมเพื่อย้ายการตัดยอดตามระบบเดิม ไม่สร้างรายจ่ายซ้ำ การตรวจสอบอ่านทะเบียนจริงใหม่ทุกครั้ง ไม่ตั้งสถานะเสร็จโดยอัตโนมัติ

รายการเบิก เอกสารอ้างอิง และประวัติยืมเงินเดิมยังอยู่ต้นทาง ไม่ย้ายตามยอดที่แบ่ง เก็บสภาพทะเบียนและโครงการก่อน/หลังใน budget_operations เพื่อการตรวจสอบ การเพิ่มกิจกรรมไม่จัดสรรหรือแก้ไขข้อมูลโครงการ 32 โดยอัตโนมัติ
