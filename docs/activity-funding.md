# การเพิ่มกิจกรรมจากงบเดิม

ผู้ดูแลระบบและฝ่ายงบประมาณเปิด **โครงการและกิจกรรม → เพิ่มกิจกรรม** แล้วเลือกฝ่าย โครงการ ชื่อ และผู้รับผิดชอบ

- **แบ่งจากงบเดิม** (ค่าเริ่มต้น): เลือกประเภทเงินและแหล่งงบต้นทาง กรอกยอดแบ่งให้กิจกรรมใหม่ ระบบหักจากยอดจัดสรรต้นทางและเพิ่มให้กิจกรรมใหม่ในธุรกรรมเดียว ยอดจัดสรร รายรับ และยอดคงเหลือรวมของโครงการ/ฝ่ายงานเท่าเดิม
- **เพิ่มงบใหม่**: ใช้เมื่อได้รับเงินเพิ่ม ยอดที่กรอกจะเพิ่มยอดรวมโครงการและฝ่ายงาน กรอก 0 ได้หากต้องการสร้างกิจกรรมไว้ก่อน

แหล่งงบเดิมเลือกได้ทั้งงบโครงการที่ยังไม่แยกกิจกรรม และกิจกรรมเดิมในประเภทเงินเดียวกัน แบ่งได้ไม่เกินยอดคงเหลือและยอดจัดสรรต้นทาง ระบบอ่านทะเบียนล่าสุดและตรวจ revision อีกครั้งก่อนบันทึก หากข้อมูลเปลี่ยนให้เปิดหน้าต่างเพิ่มกิจกรรมใหม่

รายการเบิก เอกสารอ้างอิง และประวัติยืมเงินเดิมยังอยู่ต้นทาง ไม่ย้ายตามยอดที่แบ่ง เก็บสภาพทะเบียนและโครงการก่อน/หลังใน budget_operations เพื่อการตรวจสอบ การเพิ่มกิจกรรมไม่จัดสรรหรือแก้ไขข้อมูลโครงการ 32 โดยอัตโนมัติ
