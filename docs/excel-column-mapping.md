# Mapping คอลัมน์จาก Excel ปีงบประมาณ 2569 — รอบแรก

## แผนงบประมาณ
ไฟล์: `งบประมาณปีงบ 2569 แก้ไข รอบ2(1).xlsx`

แท็บ `โครงการ2569`:
- A: ที่ / ลำดับโครงการ (บางแถวเป็นชื่อฝ่าย)
- B: โครงการ/กิจกรรม (อาจมีข้อความต่อหลายแถว)
- C: เงินอุดหนุนรายหัว
- D: เงินกิจกรรมพัฒนาผู้เรียน
- E: เงินรายได้สถานศึกษา
- F: เงินอื่น ๆ
- G: ผู้รับผิดชอบ
- H เป็นต้นไป: ยอดใช้ไป/คงเหลือ แยกตามแหล่งเงิน **ต้องตรวจคู่หัวตารางก่อนแมป**
- แถว 1–3: หัวตารางหลายชั้น ไม่ใช่รายการข้อมูล

แท็บ `Sheet1` (สรุปตามฝ่าย):
- B: ฝ่าย
- C: จำนวนโครงการ
- D: เงินอุดหนุนรายหัว
- E: เงินกิจกรรมพัฒนาผู้เรียน
- F: เงินรายได้สถานศึกษา
- G: เงินอื่น ๆ
- H: รวม

ผลรวมที่อ่านได้จากแถวรวม:
- เงินอุดหนุนรายหัว 2,129,694 บาท
- เงินกิจกรรมพัฒนาผู้เรียน 398,000 บาท
- เงินรายได้สถานศึกษา 128,000 บาท
- เงินอื่น ๆ 531,000 บาท
- รวม 3,186,694 บาท / 39 โครงการ

## ทะเบียนคุมฝ่ายทั่วไป
ไฟล์: `ทะเบียนคุมเงินบริหารทั่วไป 2569.xlsx`

แท็บ `โครงการทั้งหมด` และแท็บรายโครงการ:
- B: เลขโครงการ/เลขกิจกรรม
- C: ชื่อโครงการ/กิจกรรม
- D: เงินอุดหนุนรายหัว
- E: เงินกิจกรรมพัฒนาผู้เรียน
- F: เงินรายได้สถานศึกษา
- G: เงินอื่น ๆ
- H: ผู้รับผิดชอบ

ส่วนตารางรายการเบิกจ่ายที่พบในแท็บรายโครงการ:
- B: วันที่
- C: รายการ
- D: งบประมาณที่ได้รับจัดสรร
- E: จำนวนเงินที่ใช้
- F: คงเหลือ
- G: หมายเหตุ
- H: ใช้ไปทั้งหมด

**ข้อควรระวัง**: ตารางข้อมูลโครงการและตารางเบิกจ่ายอยู่ในชีตเดียวกันคนละช่วงแถว; ห้ามอ่านทั้งคอลัมน์ E เป็นยอดเบิกจ่ายโดยไม่ตรวจหัวตารางก่อน

## การตรวจสอบก่อน import
1. อ่านหัวตารางของแต่ละชีตแยกกัน เพราะโครงสร้างส่วนทะเบียนอาจต่างกัน
2. ระบุช่วงแถวข้อมูลโครงการและช่วงแถวธุรกรรมให้แน่นอน
3. รวมข้อความกิจกรรมที่ขึ้นบรรทัดใหม่โดยไม่สร้างกิจกรรมซ้ำ
4. ตรวจแถวรวม แถวสูตร ยอดติดลบ และรายการโอน/คืนเงิน
5. ตรวจยอดสรุปกับรายการจริงก่อนแสดงยอดใช้ไปบน Dashboard
6. ห้ามอัปโหลดข้อมูลส่วนบุคคล/รายการเบิกจ่ายลง repo แบบ Public; นำเข้าผ่านช่องทางที่มีสิทธิ์เท่านั้น

สถานะ: mapping รอบแรก ตรวจจากต้นฉบับแล้วเฉพาะแท็บที่ระบุ; ไม่ใช่การยืนยันว่าไฟล์ทะเบียนทั้ง 39 โครงการมีรูปแบบเดียวกัน
