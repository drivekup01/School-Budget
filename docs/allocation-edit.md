# Editing project allocations

Budget department and administrators can use **โครงการและกิจกรรม → แก้ไขงบประมาณ** at the top of the normal project page. Select department, project and activity to edit its four fund amounts. A project without activities has four editable fund amounts itself. Activity and project totals are read-only sums updated on input. There is no redistribution, proportional allocation or editable total. Only the selected activity's fund values are changed; other activities remain as loaded. After changing an amount, save or return to the project tab to discard before choosing another record. An unsaved-change confirmation protects navigation within the page.

Saving requires a reason. The server checks current canonical roles, fiscal-year locks, register revision, valid cents and sufficient remaining balances. Existing expense records, borrowing records, block IDs and financial document references remain intact. Additional receipts and loan balances remain separate from the opening allocation. Public project/activity/department totals and register revision update in one transaction. `budget_operations/allocation-{requestId}` retains actor, reason, original and resulting register/project data, and deduplicates retries. No real financial records are changed by automated tests.
