# School-Budget

ระบบงบประมาณของโรงเรียนค่ายบางระจันวิทยาคม แยกจาก School-Portal และ School-Procurement

## หน้าที่ใช้งาน

- `index.html` เปิดภาพรวมงบประมาณ
- `budget-dashboard.html` / `.css` / `.js` ภาพรวมและการ์ดรายรับ–คงเหลือ
- `budget-projects.html` / `.css` / `.js` โครงการและกิจกรรม
- `budget-balances.js` สรุปรายรับและยอดคงเหลือจาก Sheet ยอดคงเหลือ
- `budget-project-ledgers.js` รายการทะเบียนใช้เงินรายโครงการ
- `budget-data.json` สำเนาข้อมูลหลักจากทะเบียนคุมเงินบริหารวิชาการ 2569 ยังไม่ซิงก์อัตโนมัติ
- `budget-sidebar.js` / `.css` Sidebar กลางที่ระบบเอกสารเรียกใช้ร่วมกัน
- `legacy-dashboard.html` หน้าทดลองเดิมที่เก็บไว้ก่อนย้ายระบบ ไม่ใช่หน้าหลัก

## การยืมงบประมาณ

- ผู้ดูแลกด **เพิ่มการยืมเงิน** ในโครงการปลายทางแล้วจึงเปิดฟอร์ม เลือกฝ่าย/โครงการ/ทะเบียนต้นทางและดูยอดทั้งสองฝั่งก่อนบันทึก
- รองรับปีเดียวกันและประเภทงบเดียวกัน รวมถึงกิจกรรมที่มีทะเบียนแยกในโครงการเดียวกัน; ไม่เดายอดกิจกรรมที่ยังไม่มีทะเบียนแยก
- `apps-script/Borrowing.gs` บันทึกรายการกลางหนึ่งแถวในแท็บ `ทะเบียนยืมงบประมาณ` ของสำเนาวิชาการตามปี ทุกฝั่งคำนวณจากรายการกลางเดียวกัน แยกจากรายจ่าย
- ไม่เขียนรายการยืมเป็นค่าใช้จ่ายในคอลัมน์ E/H ของทะเบียนเดิม และไม่แก้งบตั้งต้น: ยอดหน้าเว็บ = คงเหลือทะเบียนค่าใช้จ่าย + รับยืม − ให้ยืม ดังนั้นคอลัมน์ F ในชีทเดิมเป็นยอดก่อนรวมทะเบียนการยืม
- บันทึกภายใต้ล็อก ตรวจยอดและ revision ทั้งสองฝั่ง ใช้ request ID ป้องกันซ้ำ และตรวจสิทธิ์ admin ที่เซิร์ฟเวอร์
- ยกเลิกด้วยรายการย้อนกลับที่อ้างอิงรหัสเดิม ไม่ลบประวัติ และไม่ให้คืนยอดจนปลายทางติดลบเพิ่มจากก่อนยืม
- `budget-borrowing.js` แสดงฟอร์ม/ประวัติพร้อมลิงก์ต้นทางปลายทาง ส่วน `budget-live-data.js` รวมผลการยืมล่าสุดเข้าข้อมูลนำเข้าของหน้าภาพรวม/โครงการ โดยไม่เพิ่มยอดรายรับรวมโรงเรียน
- การใช้จ่ายและการแก้ข้อมูลใน Excel ยังไม่มีการซิงก์ยอดฐานของภาพรวมอัตโนมัติ รายการยืมอ่านจากระบบจริงทุกครั้งที่เปิดหน้า
- โครงการที่มีประวัติการยืมอ่านคงเหลือทะเบียนล่าสุดจากสำเนาด้วย เพื่อให้ค่าใช้จ่ายหลังยืมลดยอดบนหน้าภาพรวมและโครงการตามกัน; โครงการที่ยังไม่มีรายการยืมยังใช้ข้อมูลฐานนำเข้า
