โครงการ Apps Script: https://script.google.com/home/projects/1ZdNJsQPymtFJeFWebhpXN2Dl8fvvspJNM07Ahnvk4gMbCXk_qZX5OJzF/edit

Web app: https://script.google.com/macros/s/AKfycbwrzdF3tfWbHDy32IeknlDDvEiIAGA-ZsB7D9BR7FzATjk68pbFxLI_4oDg-xBnGsrS2g/exec

โค้ดเวอร์ชันที่เตรียมไว้ไม่จำกัดบัญชีผู้ใช้ ตั้งค่า Execute as = ฉัน (drivekup01@gmail.com) และสิทธิ์เข้าใช้ = ทุกคน ผู้มีลิงก์จะอ่านและบันทึกทะเบียนสำเนาได้โดยไม่ต้องล็อกอิน เผยแพร่เวอร์ชัน 3 แล้วเมื่อ 14 ตุลาคม 2569 บัญชีเจ้าของเว็บแอปได้รับสิทธิ์แก้ไขไฟล์สำเนา 4 ไฟล์แล้ว

เปิดฟอร์มด้วย `?project=23` โดย project เป็นเลขโครงการ 1–39 โค้ดเลือกได้เฉพาะไฟล์สำเนา 4 ไฟล์ที่กำหนด ห้ามส่ง spreadsheetId จากเบราว์เซอร์

## ขั้นตอนทำงาน

1. เจ้าของเว็บแอปอนุญาตสิทธิ์ Google ครั้งแรก ผู้ใช้งานทั่วไปไม่ต้องอนุญาตแยก
2. เซิร์ฟเวอร์ค้นหาหัวตารางทะเบียนจากชื่อคอลัมน์ ไม่ยึดแถว 14
3. ผู้ใช้เลือกชุดทะเบียน กรอกเลขเอกสาร วันที่ รายการ จำนวนเงิน และหมายเหตุ
4. หน้าเว็บแสดงยอดคงเหลือหลังหักทันที แต่ยังไม่เขียนจนกดบันทึก
5. เซิร์ฟเวอร์อ่านยอดใหม่ ตรวจ revision และล็อกการเขียนก่อนเพิ่มแถว โดยรักษาตารางอื่นในชีท
6. บันทึก F เป็นสูตรคงเหลือ และ H เป็นยอดใช้สะสม โหลดรายการจริงกลับมาแสดง

ไม่รองรับการยืมข้ามโครงการและไม่อนุญาตบันทึกเกินยอดคงเหลือในรอบนี้ ยังไม่อัปเดต snapshot ของ Dashboard อัตโนมัติ

## การทดสอบ

ทดสอบ parser, การคำนวณ, สูตร, ป้องกันรายการซ้ำ, revision ที่ล้าสมัย, ยอดไม่พอ และการใช้งานโดยไม่จำกัดบัญชีด้วย Spreadsheet mock รวมถึงแบบฟอร์มและหน้าจอมือถือด้วย RPC mock ตรวจเว็บแอปจริงอ่านชุดทะเบียนโครงการ 1 ได้ ยอดตั้งต้น 38,994.00 บาทและคงเหลือ 30,454.00 บาท ตรวจ HTTP แบบไม่มีเซสชันได้สถานะ 200 และแสดงฟอร์มโดยไม่ส่งไปหน้าเข้าสู่ระบบ ยังไม่ได้เพิ่มรายการทดสอบลง Sheet จริง

## แบบฟอร์มบน GitHub

แบบฟอร์มใช้งานจริงอยู่ที่ https://drivekup01.github.io/School-Budget/budget-entry.html?project=1 และปุ่มของทั้ง 39 โครงการเปิดหน้านี้ตาม project แต่ละรายการ ใช้ budget-api.js เชื่อมผ่าน iframe ของ Apps Script เวอร์ชัน 4 โดยตรวจ origin และอนุญาตเฉพาะการอ่านทะเบียนและบันทึกรายการ ใช้ไฟล์สำเนาทั้ง 4 ฝ่ายตาม WORKBOOKS เท่านั้น

ในรอบนี้ฟอร์มเพิ่มรายการใช้เงินและอ่านรายการเดิม การแก้ไขแถวที่บันทึกไปแล้วและการยืมข้ามโครงการยังไม่ได้เพิ่ม

ตรวจข้อมูลจริงด้วย Google Sheets: ทั้ง 39 แท็บโครงการมีหัวตารางทะเบียนที่ตรงตัวอ่าน และมีข้อมูลยอดตั้งต้น/คงเหลือสำหรับชุดทะเบียนที่ตรวจในช่วง A1:H100 ครบทั้ง 4 ฝ่าย

## บัญชีและสิทธิ์
ใช้ Auth.gs ร่วมกับ Code.gs ฐานบัญชีเป็น Sheet ส่วนตัว แยกจากไฟล์งบและไฟล์สำเนาทดสอบ รหัสผ่านไม่อยู่ใน GitHub เก็บ PBKDF2-SHA256 verifier พร้อม salt (150,000 รอบ) ผู้ใช้ยืนยันผ่าน challenge แบบใช้ครั้งเดียว เซสชันตรวจที่เซิร์ฟเวอร์และหมดอายุภายใน 4 ชั่วโมง

admin1 และ admin2 ใช้สิทธิ์ admin; editor1 ใช้สิทธิ์ editor อ่านทะเบียนงบได้แต่ saveBudgetEntry ปฏิเสธ ฝั่งเอกสารทุกบัญชีเข้าใช้ได้หลังตรวจเซสชันจากตัวเชื่อมงบประมาณ การลงชื่อออกยกเลิกเซสชันฝั่งเซิร์ฟเวอร์ มีการจำกัดการเข้าสู่ระบบผิด 5 ครั้งต่อบัญชีใน 5 นาที
