ตั้งค่า Execute as = ผู้ใช้ที่เข้าถึงเว็บแอป และสิทธิ์เข้าใช้ = เจ้าของเท่านั้น สำหรับรอบแรก บัญชีผู้ดูแลในโค้ดคือ drivekup01@gmail.com

เปิดฟอร์มด้วย `?project=23` โดย project เป็นเลขโครงการ 1–39 โค้ดเลือกได้เฉพาะไฟล์สำเนา 4 ไฟล์ที่กำหนด ห้ามส่ง spreadsheetId จากเบราว์เซอร์

## ขั้นตอนทำงาน

1. เจ้าของอนุญาตสิทธิ์ Google ครั้งแรก
2. เซิร์ฟเวอร์ค้นหาหัวตารางทะเบียนจากชื่อคอลัมน์ ไม่ยึดแถว 14
3. ผู้ใช้เลือกชุดทะเบียน กรอกเลขเอกสาร วันที่ รายการ จำนวนเงิน และหมายเหตุ
4. หน้าเว็บแสดงยอดคงเหลือหลังหักทันที แต่ยังไม่เขียนจนกดบันทึก
5. เซิร์ฟเวอร์อ่านยอดใหม่ ตรวจ revision และล็อกการเขียนก่อนเพิ่มแถว โดยรักษาตารางอื่นในชีท
6. บันทึก F เป็นสูตรคงเหลือ และ H เป็นยอดใช้สะสม โหลดรายการจริงกลับมาแสดง

ไม่รองรับการยืมข้ามโครงการและไม่อนุญาตบันทึกเกินยอดคงเหลือในรอบนี้ ยังไม่อัปเดต snapshot ของ Dashboard อัตโนมัติ

## การทดสอบ

ทดสอบ parser, การคำนวณ, สูตร, ป้องกันรายการซ้ำ, revision ที่ล้าสมัย, ยอดไม่พอ และสิทธิ์ผู้ดูแลด้วย Spreadsheet mock รวมถึงแบบฟอร์มและหน้าจอมือถือด้วย RPC mock การทดสอบอ่าน/บันทึกจริงรอเจ้าของอนุญาต Google ครั้งแรก
